--MiniUFOAttack---------------------------------

Movements : 
	Arrows of the keyboard
	W for QWERTY or Z for AZERTY -> up
	Q for QWERTY or A for AZERTY -> left
	S -> down
	d -> right

	SPACE -> shoot lasers




Each Enemy prefab need to have the "Enemy" label

Animations : 
  The alien in the UFO blinks every 5 seconds
